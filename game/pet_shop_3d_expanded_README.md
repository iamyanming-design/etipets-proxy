# 毛球小日子 3.0｜東森寵物・擴建與養成版

Game Designer: PO CHEN YEN

在 2.1 品牌版上擴充。保留東森寵物 LOGO、原有犬貓、金幣、設備升級、
藍色場景、店員、背景音樂與音效，新增網格擺設、共享尋路、
設備經濟效果、店員自動照顧、12 位夥伴與親密度。

## 開啟遊戲

直接以電腦瀏覽器開啟 `index.html`，點「開啟我的小店」。
交付的 `pet_shop_3d_expanded.html` 與此檔案內容相同。
不需安裝程式、登入、網路連線、API 金鑰或 CDN。
PNG LOGO、程式、音樂合成器與樣式均已內嵌。沒有真實付款功能。

建議使用電腦 Chrome 或 Edge。支援桌機、窄視窗與手機響應式排版；
手機是觸控旋轉與點選，不是第一人稱操作。
WebGL2 不可用時會嘗試 Canvas 3D 相容繪製；裝置效能會影響流暢度。

新遊戲：650 金幣、18 份飼料、2 位毛孩、3 位店員、
1 張地毯與 1 盆植栽。這些初始裝飾免費，回收不產生金幣。
測試截圖的已購設備、毛孩數與金庫只是進度示例，不是新遊戲預設值。

## 先玩這五步

1. 選擇奶油或麻糬，補足較低的需求，獲得金幣與店鋪經驗。
2. 到「設備選物所」買一座豪華貓爬架，點地板選位並確認。
3. 升至店鋪 Lv.2 後，在「迎接新夥伴」安置第三位毛孩。
4. 添購洗澡台、展示架與餵食器，增加營收、庫存及自動照顧能力。
5. 在右側「店員」逐位啟用自動照顧；安排裝飾提升溫馨值與 VIP 機率。

核心循環：
照顧毛孩／顧客消費 → 金幣與店鋪經驗 → 設備購買與升級 →
增加容納與收益 → 飼養更多毛孩 → 更多照顧與經營機會。

## 真正擴大的空間

- 新門市地面為 28 × 22 個一單位網格，共 616 格。
- 上一版門市基座範圍是 17.6 × 13.6 世界單位。
  新範圍的寬約 1.59 倍、深約 1.62 倍，面積約 2.57 倍。
  這是長、寬各擴建約 1.6 倍，不是把同一張小地圖縮小顯示。
- 固定櫃台、原有照護區、牆邊貨架等占用格不能再放新設備。
- 店員、顧客、寵物共用 0.5 單位解析度、55 × 43 節點的 A* 尋路網。
  網格會依實際家具碰撞體更新，禁止斜向切角，路徑以可視直線簡化。
- 寵物與店員的巡邏目的地從擴建後可連通地面抽取。
- 正交相機依中央畫布尺寸及房間外框計算完整視野；
  全店模式不把左右介面空間算入可視範圍。放大後支援有邊界的平移。

## 網格擺設與交易

「設備選物所」選擇商品 → 點選地板 → 旋轉／微調 → 確認擺放。
選購時不扣款；通過檢查並確認才付款。紅色預覽不能放置，綠色可放置。

檢查：地面邊界、家具占格、固定設施、角色碰撞、入口、等待區、
補貨／服務／設備互動點及連通性。不能用家具把既有可用通道封死。
圍欄有實際入口；地毯可踩踏；壁紙不阻擋地面；其他家具依碰撞體繞行。
每間店最多 36 件可擺設設備。固定房間家具不屬於可搬動清單。

右側「設備」可查看、移動、升級、回收已放置設備：
移動免費；回收退還累積實付金額 40%，小數無條件捨去。
不能回收會讓現有毛孩失去名額的容納設備。
移除展示架造成的超額貨品會退回倉庫，不直接消失。
擺設時暫停模擬；取消擺設不扣金幣。

### 設備規格

價格欄依序是 Lv.1 購買／升 Lv.2／升 Lv.3 的金幣。
升級至少須達設備本身解鎖等級與目標設備等級，兩者取較高者。

| 設備 | 占格 | 解鎖店鋪等級 | 三段價格 | Lv.1 / Lv.2 / Lv.3 實際效果 |
| --- | --- | --- | --- | --- |
| 自動餵食器 | 2×2 | 2 | 240 / 280 / 430 | 用餐後飽食度補至 100；冷卻 45 / 32 / 22 秒 |
| 毛孩洗澡台 | 3×2 | 2 | 320 / 380 / 600 | 解鎖美容訂單；美容服務額外加價 0% / 20% / 40% |
| 進階展示架 | 3×1 | 1 | 180 / 240 / 380 | 貨架上限 +18 / +30 / +42 件 |
| 豪華貓爬架 | 2×2 | 1 | 160 / 230 / 350 | 毛孩上限 +1 / +2 / +3；溫馨 +2 / +4 / +6 |
| 小狗遊戲圍欄 | 3×3 | 2 | 280 / 340 / 500 | 毛孩上限 +2 / +3 / +4；溫馨 +2 / +4 / +6 |
| 雲朵拼色地毯 | 3×2 | 1 | 90 / 120 / 180 | 溫馨 +5 / +9 / +14；可在上面休息 |
| 療癒綠植盆栽 | 1×1 | 1 | 70 / 100 / 150 | 溫馨 +4 / +7 / +10；升級後外觀變大 |
| 星夜特色壁紙 | 3×1 | 3 | 200 / 280 / 400 | 溫馨 +10 / +16 / +24；後牆第一排或轉向左牆第一列 |

展示架的加成是該件設備目前等級的總效果，不是每級累加：
原有 18 件貨架 + 一件 Lv.1 展示架 = 36 件，
升至 Lv.2 後 = 48 件，升至 Lv.3 後 = 60 件。
放置多件時各件目前效果相加。容納設備最多將總名額提高至 12 位。

餵食器需要毛孩實際走到設備前，且庫存有飼料；每次吃掉 1 份，
不是免費無限補食。多隻毛孩共用設備冷卻。
洗澡台在店員抵達並完成美容工作後才結算；工作時有泡泡與肢體動畫。
店內原有的 CARE CORNER 是原始照護布景，新購洗澡台才解鎖付費美容訂單。

## 毛孩照顧與親密度

飽食度、整潔度、心情值與體力皆在 0–100 間，營業時間會緩慢下降。
玩家可餵食、梳毛照護、逗玩、休息；狀態已足夠時不讓玩家重複刷獎勵。
每次有效手動照顧 +6 金幣、+8 店鋪經驗；
店員或自動餵食器有效照顧 +2 金幣、+4 店鋪經驗。
毛孩自己的成長經驗與店鋪經驗、親密經驗是不同數值。

親密度 Lv.1–Lv.10：
- 有效手動照顧 +6 親密經驗；店員／餵食器照顧 +3。
- 飽食度、整潔度、心情均至少 70、體力至少 30 時，
  每模擬秒另增加 0.055 親密經驗。
- 等級門檻：0、20、55、105、175、270、390、540、720、930。
- Lv.3 擊掌、Lv.5 撒嬌、Lv.8 幸福舞；有獨立動畫。
- 專屬互動有共用 60 秒冷卻，不可無限重按：
  提升心情、親密經驗，給予 10 金幣與 5 店鋪經驗。
- 每位毛孩高於 Lv.1 的每級提供 0.4% 全店收益加成，
  親密度加成全店合計上限 30%。

共 12 位獨特夥伴，每位只能安置一次：
柯基、英短、柴犬、博美、玩具貴賓、布偶、
米格魯、曼赤肯、暹羅、垂耳兔、黃金鼠、緬因貓。
各有等級、準備金與部分溫馨門檻；暹羅和緬因標示稀有。
迎接毛孩不會販售毛孩，金幣被描述為安置準備金。
本作是風格化遊戲，不是現實飼養、混養或醫療指引。

## 店員與經濟

三位店員：小藍、小晴、阿澄。原本補貨、拖地、接待能力保留。
右側「店員」可以選人手動派照顧，也能逐位勾選自動照顧。
新遊戲先開啟小晴的自動照顧；其他員工可自行開啟。
員工會先預約目標、走到現場、播放工作動作，再提交結果。
毛孩被預約照顧時會等待店員，避免追逐移動目標。

貨架商品和餵毛孩的飼料是兩種資源：
- 倉庫商品 24 件 / 60 金幣；由店員搬到貨架，商品客人每次買 2 件。
- 毛孩飼料 10 份 / 40 金幣；每日另可領一次免費 10 份。
- 自動進貨、自動買飼料預設關閉，須在店員頁自行啟用。
  倉庫低於 6 或飼料低於 3 時才按固定包裝購入；金幣不足就不買。

溫馨值 = 10 + 原版裝飾升級×4 + 已擺設備溫馨總和，最高 100。
VIP 機率：溫馨低於 25 時為 0；25 時為 10%，之後每點 +0.4 個百分點，
上限 40%。VIP 是實際訂單屬性，不只是介面標示，支付一般訂單的 1.6 倍。
溫馨也略為縮短到客間隔，並提供每點 0.2% 收益加成。

顧客基礎報酬：
商品 75、互動 80、美容 135、照護體驗 100 金幣。
毛孩狀態與庫存不足會影響訂單能否接待，客人具有耐心時間。

全店倍率 =
(1 + 原版裝飾等級×12% + 溫馨×0.2% + 親密加成
   + 第三位起每多一位毛孩×2.5%，這部分上限40%)
× (清潔度至少85時為1.1，否則1)。

再乘上 VIP 的 1.6 或 1，美容訂單再乘洗澡台等級的加價倍率，
最後四捨五入為金幣。左側「小店成長帳」即時呈現名額、溫馨和全店加成。
以上是顧客收入加成，不會把每日任務或每次手動照顧獎金也乘上倍率。

每遊戲日 300 秒，提供任務與結算獎金；打烊後按鈕確認進入下一天。
只有遊戲可見且營業中才模擬。切換分頁、開啟對話框、擺設與暫停會停止
經濟／狀態進程；不計算關閉瀏覽器後的離線收益。

## 原有進度與備份

從原版、藍色版或東森品牌版：
舊遊戲「設定 → 匯出」JSON → 新遊戲「設定 → 匯入」→ 確認。
支援存檔 version 1 / 2 / 3。

保留金幣、寵物、原有成長、設備升級、店名、日數、店員設定等有效欄位。
原先已擁有超過 2 位毛孩的舊存檔會保留足夠的基礎名額，不刪除夥伴。
舊版照顧次數會轉為初始親密經驗；新增設備從初始地毯與植栽開始。
舊位置若落在新家具中，會搬至最近的可走位置。
未完成訂單／工作不跨重新載入保存；庫存交易於完成時提交，
因此未完成的搬運不會提前扣掉商品或重複付款。

新版在 `little-paw-days-save-v3` 儲存，每 12 秒及重要交易時保存。
第一次載入可讀取同一儲存來源中的 v2／v1，但不同 HTML 路徑的
瀏覽器儲存行為可能不同，因此建議一律使用匯出／匯入搬移進度。
不是雲端同步。換裝置、清除瀏覽器資料、移動 HTML 前請先匯出。
自動保存被阻擋時，畫面會提示；仍可使用 JSON 匯出功能。
匯入會覆蓋目前新版進度，請先備份。
修改遊戲資料的非官方存檔不在正常流程保證範圍。

## 原始碼與建置

- `src/config.js`：地圖、設備目錄、親密門檻與設備存檔結構。
- `src/expansion.js`：碰撞與 A*、放置交易、店員照顧、設備與收益、UI。
- `src/world.js`：擴建門市、地板材質、固定家具與原版升級外觀。
- `src/operations.js`：人物模型、店員定義、固定碰撞、工作動畫與介面。
- `src/game.js`：基本狀態、存檔、角色與既有遊戲系統；
  `legacy*` 函式保留作舊版對照，新增同名入口由 expansion.js 提供。
- `src/mini3d.js`：原生 WebGL2 與 Canvas 相容 3D renderer，正交視野自動適配。
- `src/audio.js`：原創 Web Audio 音樂與音效。
- `src/brand.js`、`assets/etpet-logo.png`：品牌招牌。
- `src/template.html`、`src/style.css`：介面與響應式樣式。
- `build.py`：把上述檔案打包為完全離線的 `index.html`。

修改後在本資料夾執行：
```sh
python build.py
```

測試：參閱 `QA.md`、`qa/report.json` 與 `qa/extended-report.json`。
QA 腳本需 Python Playwright 及本機 Chromium，遊戲本身不需要這些工具。
